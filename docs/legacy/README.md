# Legacy upload

`python project.zip` is the original archive that shipped with this repository.
It contains only the folder skeleton of a `NumberPlateRecognition` project —
`images/`, `output/`, `src/` and `tests/` — with **no source files, no
dependencies and no build**. Nothing in it was executable, deployable or
testable, so it is kept here for provenance only.

The platform in the repository root is a from-scratch rebuild that keeps the
same intent (number-plate recognition) and turns it into a deployable commercial
product: a real ALPR engine, multi-tenant API, operator console, audit trail and
deployment tooling. See the top-level `README.md`.
